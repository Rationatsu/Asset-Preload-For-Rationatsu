# Asset Preload - Rationatsu Art

Repository ini berisi kumpulan aset digital (seperti file audio, gambar, dan elemen pendukung lainnya) yang digunakan untuk mendukung performa dan *preloading* konten pada project web portofolio saya di [rationatsu.base44.app](https://rationatsu.base44.app).

##  Struktur Folder
* **/data/Audio/** : Berkas audio/musik yang di-preload untuk pengalaman web yang lebih lancar.
* **/data/Archive/** : Arsip aset cadangan atau file terkompresi.

##  Penggunaan
Aset-aset di dalam repository ini dikelola secara khusus untuk kebutuhan integrasi web interaktif dan media digital milik **Rationatsu**.
